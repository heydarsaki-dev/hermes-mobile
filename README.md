# 📱 هرمس — کلاینت اندروید

اپلیکیشن اندروید برای تعامل کامل با **Hermes Agent** که روی Termux اجرا می‌شود.

## ✨ امکانات

| بخش | توضیح |
|---|---|
| 💬 **چت** | ارسال پیام، استریم زنده پاسخ، نمایش تفکیک فکر/ابزار/پاسخ |
| 🧠 **مدل و پرووایدر** | انتخاب مدل، پرووایدر، دما، توکن و پارامترهای نمونه‌برداری |
| 🧰 **ابزارها** | فعال/غیرفعال کردن تک‌تک ابزارها و ابزارهای داخلی |
| 🔌 **مهارت و پلاگین** | مدیریت مهارت‌ها و افزونه‌ها |
| 💾 **نشست‌ها** | لیست، جستجو، ادامه و حذف نشست‌های تاریخی |
| ⏰ **کرون** | زمان‌بندی اجرای خودکار تسک‌ها |
| 🖥️ **ترمینال** | دسترسی مستقیم به PTY هرمس |
| ⚙️ **تنظیمات** | آدرس سرور، توکن، آمار مصرف منابع |

## 🎨 طراحی

- رابط کاربری کاملاً **فارسی و راست‌به‌چپ**
- تم مدرن شیشه‌ای (Glassmorphism) با انیمیشن نرم
- تاریخ شمسی در تمام بخش‌ها
- طراحی شده برای گوشی و تبلت

## 🔌 نحوه اتصال

۱. روی ترموکس، سرور هرمس را اجرا کنید و آدرس IP دستگاه را یادداشت کنید.
۲. در اپ، آدرس را وارد کنید: `http://<ip>:8000`
۳. توکن از متغیر `HERMES_DASHBOARD_SESSION_TOKEN` هرمس می‌آید.

## 📦 هرمس درون اپ (بدون ترموکس)

از صفحهٔ اتصال می‌توانید هرمس را داخل خودِ گوشی نصب و اجرا کنید. APK دیگر
rootfs را در خود ندارد تا سبک بماند:

- باینری‌های `proot` و `loader` و کتابخانه‌هایشان (~۳۰۰ کیلوبایت) داخل APK می‌مانند.
- دادهٔ سیستمی (`rootfs.tar.gz`، ~۷۶ مگابایت) هنگام نصب از asset ریلیس
  [`runtime-v1`](https://github.com/heydarsaki-dev/hermes-mobile/releases/tag/runtime-v1)
  دانلود می‌شود و پس از استخراج پاک می‌گردد.
- دانلود با پشتیبانی ادامهٔ دانلود (HTTP Range) و بررسی SHA-256 انجام می‌شود.
- فضای لازم روی حافظه: ~۳۸۰ مگابایت خالی (۲۵۳MB ریشه + فایل فشرده + حاشیه).
- پکیج استاندارد `unittest` پایتون (که در rootfs حذف شده بود) به‌صورت یک تکهٔ
  کوچک داخل APK می‌آید و هنگام نصب — و در صورت لزوم در هر اجرا — به rootfs
  برگردانده می‌شود؛ بدون آن هر نوبت چت با خطای «No module named 'unittest'»
  شکست می‌خورد.
- سقف انتظار آماده‌شدن ایجنت در `tui_gateway/server.py` از ۳۰ به ۳۰۰ ثانیه
  افزایش می‌یابد؛ ساخت ایجنت روی گوشی می‌تواند از ۳۰ ثانیه بگذرد و در آن حالت
  چت با «agent initialization timed out» بی‌پاسخ روی «خطا» می‌ماند.

## 🛠 ساخت از منبع

```bash
git clone https://github.com/heydarsaki-dev/hermes-mobile.git
cd hermes-mobile
gradle assembleDebug
```

APK در `app/build/outputs/apk/debug/` ساخته می‌شود.

## ⚙️ GitHub Actions

با هر push به شاخه `main`، بیلد خودکار اجرا می‌شود و APK به‌عنوان Artifact بارگذاری می‌گردد.
