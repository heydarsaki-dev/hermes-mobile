# 📱 هرمس — کلاینت اندروید

اپلیکیشن اندروید برای تعامل کامل با **Hermes Agent** که روی Termux اجرا می‌شود.

## ✨ امکانات

| بخش | توضیح |
|---|---|
| 💬 **چت** | ارسال پیام، استریم زنده پاسخ، نمایش تفکیک فکر/ابزار/پاسخ |
| 🧠 **مدل و پرووایدر** | انتخاب مدل، پرووایدر، دما، توکن و پارامترهای نمونه‌برداری |
| 🧰 **ابزارها** | فعال/غیرفعال کردن تک‌تک ابزارها و ابزارهای داخلی |
| 🔌 **مهارت و پلاگین** | مدیریت مهارت‌ها و افزونه‌ها |
| 💾 **نشست‌ها** | لیست، جستجو، ادامه و حذف نشست‌های تاریخی |
| ⏰ **کرون** | زمان‌بندی اجرای خودکار تسک‌ها |
| 🖥️ **ترمینال** | دسترسی مستقیم به PTY هرمس |
| ⚙️ **تنظیمات** | آدرس سرور، توکن، آمار مصرف منابع |

## 🎨 طراحی

- رابط کاربری کاملاً **فارسی و راست‌به‌چپ**
- تم مدرن شیشه‌ای (Glassmorphism) با انیمیشن نرم
- تاریخ شمسی در تمام بخش‌ها
- طراحی شده برای گوشی و تبلت

## 🔌 نحوه اتصال

۱. روی ترموکس، سرور هرمس را اجرا کنید و آدرس IP دستگاه را یادداشت کنید.
۲. در اپ، آدرس را وارد کنید: `http://<ip>:8000`
۳. توکن از متغیر `HERMES_DASHBOARD_SESSION_TOKEN` هرمس می‌آید.

## 🛠 ساخت از منبع

```bash
git clone https://github.com/heydarsaki-dev/hermes-mobile.git
cd hermes-mobile
gradle assembleDebug
```

APK در `app/build/outputs/apk/debug/` ساخته می‌شود.

## ⚙️ GitHub Actions

با هر push به شاخه `main`، بیلد خودکار اجرا می‌شود و APK به‌عنوان Artifact بارگذاری می‌گردد.
